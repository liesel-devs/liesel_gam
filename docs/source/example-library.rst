Example library
===============

These examples cover additional effects and specialized workflows. The maintained
Markdown examples execute during documentation builds; older JSON notebooks
retain saved outputs and are not execution-validated by the build. Start with
the tutorials on the :doc:`homepage <index>` for the main workflow.
